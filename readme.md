🪶 VATE Studio — Compositor de Letras para Suno AI (PWA)

Estudio de composición offline-first listo para GitHub Pages.

🚀 Despliegue en GitHub Pages
1. Sube todos estos archivos a tu repositorio respetando la estructura:
   index.html  manifest.webmanifest  sw.js
   css/styles.css
   js/config.js js/lexicon.js js/utils.js js/storage.js js/exporters.js js/app.js
   icons/icon.svg icons/icon-192.png icons/icon-512.png
2. Descarga los iconos PNG y guárdalos en icons/:
   - icons/icon-512.png ← https://image.qwenlm.ai/public_source/d2e5fad2-6974-4c4c-86a3-d5150aefcff2/18ac31750-4423-40d3-a0ba-333b66d9482f.png
   - icons/icon-192.png ← https://image.qwenlm.ai/public_source/d2e5fad2-6974-4c4c-86a3-d5150aefcff2/14efe5271-2f26-4f54-977e-79a78cde9dc3.png
3. En el repo: Settings → Pages → Branch: main → Save.
4. Abre https://TUUSUARIO.github.io/TUREPO/ y pulsa ⬇ Instalar app.

✨ Qué incluye
- Editor por secciones con meta-tags [Chorus | …], moods, dinámicas (pp–ff), cues vocales y respiración.
- Asistente: rimas consonantes/asonantes (>5000 palabras generadas offline), sinónimos, métrica/pronunciación, IA de versos por tema.
- 14 plantillas de género (pop 2026, reggaetón, trap, corrido tumbado, bolero, flamenco urbano, metal, EDM…).
- Estructura: carril visual, BPM sugerido + metrónomo WebAudio, instrumentación, comparación con canciones famosas.
- Análisis: límite Suno 5000 en vivo, densidad lírica, palabras repetidas, pegajosidad, arco emocional.
- Exportación: TXT Suno, Markdown, PDF (impresión), JSON proyecto/plantilla, MIDI y PNG para redes.
- Historial automático + manual, proyectos múltiples, importación de texto Suno y de JSON.
- PWA completa: Service Worker offline, manifest instalable, tema día/noche persistente.
